# Short note: Olist ERD and data quality

In the `customers` table, `customer_id` identifies a customer record associated with an order, while `customer_unique_id` groups records belonging to the same real-world customer; use the distinct `customer_unique_id` values to count customers. The `order_items` table is the junction table that resolves the many-to-many relationship between `orders` and `products`, because one order can contain many products and one product can appear in many orders; it also records the seller for each item. In the observed dataset, each `customer_id` record is associated with one order, which is stricter than a general ERD relationship allowing a customer to have zero or many orders. The optional circle on the `orders`–`order_items` relationship is justified because the notebook notes that 775 orders have no items, meaning an order can have zero order-item rows.
